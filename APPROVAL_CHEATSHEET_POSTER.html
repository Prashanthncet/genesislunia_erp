Step-by-step walkthroughs

The 10 processes — follow them yourself

Each card tells you what the process is for, shows the flow at a glance, then lists numbered steps — log in as this person, do this — in order. Switch logins and watch the file travel from start to finish.

1

🌟 Admission — a child joins the school9 steps · 5 approvers · the flagship workflow

Open live ↗

What it does: takes a family from “we want admission” to “your child has a roll number and a house”. Five school people say YES one after another; anyone's NO sends the file back or ends it.

AO sends link➜ Parent submits➜ AO validates docs➜ Payment➜ Accounts approves fee➜ OS: Roll No + House➜ VP YES➜ Principal signs➜ Student created 🎉
Log in as ao@sainik01.edu · Demo@Ao1 → Admissions → send the form link to a parent.
Log in as parent@sainik01.edu · Demo@Parent1 → open the link → fill the form, upload documents, submit.
Back to ao@… → check documents: good → Validate · bad → send back to parent.
Fee in: parent pays online, or accounts@sainik01.edu · Demo@Accounts1 records it → Fee Approve.
Log in as os@sainik01.edu · Demo@Os1 → Allocate → the child gets a Roll Number + House.
Log in as vp@sainik01.edu · Demo@Vp1 → Approve step 7. (His send-back erases the roll number!)
Log in as principal@sainik01.edu · Demo@Principal1 → type your name as signature → CONFIRM. Done — a real student now.
Rule: each step is a locked door — only the right role opens it, and every YES/NO is stored with a remark. The Principal's dashboard shows the whole queue in one screen.
✅ Complete & live: all 9 steps, payment, send-back loops, auto student-master creation.
2

✏️ Attendance — who came to class todaydaily roll call · instant parent alert

Open live ↗

What it does: the teacher marks every child Present / Absent / Late, and the system instantly messages the parents of absent children.

Teacher marks roll➜ Child marked Absent➜ AUTO SMS/Email to parent➜ Below-75% list feeds report cards
Log in as teacher@sainik01.edu · Demo@Teacher1 → Attendance → class 10A → mark the roll → Save.
Log in as parent@sainik01.edu · Demo@Parent1 → Portal → Attendance → the absent mark is already there.
Log in as principal@sainik01.edu · Demo@Principal1 → school-wide registers + the below-75% warning list.
Rule: only teachers, HODs and bosses mark attendance — Warden, Security and Parents can't even see this page. % = (Present+Late+OD) ÷ (Present+Late+OD+Absent); approved leave & Sundays don't count.
✅ Complete & live: bulk marking, no-repeat auto-notifications, registers, analytics.
3

💵 Fees — the school bills, the family paysinvoice → money → receipt

Open live ↗

What it does: creates a fee bill for every student each term, collects money online or in cash, issues a numbered receipt, and lists who hasn't paid.

Accounts: structure➜ Invoice INV-2026-0001➜ Parent pays / cash at office➜ Receipt RCPT + Paid ✅➜ Defaulters list
Log in as accounts@sainik01.edu · Demo@Accounts1 → Fees → set the structure → Generate invoices.
Log in as parent@sainik01.edu · Demo@Parent1 → Portal → Fees → Pay online (or accounts records cash + prints receipt).
Back to accounts@… → the invoice turns Paid → open the Defaulters list.
Rule: you can never pay more than the balance — the system refuses it. No “fee discount” screen exists; that was decided on purpose.
✅ Complete & live: sequential numbers, balance math, receipt PDFs, online collection.
4

🔐 Gate Pass — a child leaves campusthe strictest chain: 2 approvals + parent OTP + guard check

Open live ↗

What it does: nobody walks out without four checks — the Warden approves, the Principal approves, the parent consents with an OTP, and the guard verifies it at the gate.

Parent requests➜ Warden YES➜ Principal YES → OTP sent➜ Guard verifies OTP➜ Checked Out➜ Returned (+late flag)
Log in as parent@sainik01.edu · Demo@Parent1 → Portal → Gate Passes → request with a time.
Log in as warden@sainik01.edu · Demo@Warden1 → Gate → approve (1st YES).
Log in as principal@sainik01.edu · Demo@Principal1 → approve (2nd YES) → a 6-digit OTP goes to the parent.
Log in as security@sainik01.edu · Demo@Security1 → Gate Desk → enter OTP → Checked Out. On return → Check In (late = flagged).
Rule: 5 wrong OTP tries lock the pass. No OTP = no exit — even with both approvals.
✅ Complete & live: full chain, hashed OTP, QR pass PDF, visitor log, parent notified every turn.
5

🗓️ Staff Leave — a holiday… with a salary effectapply → approve → auto-dock over-quota days

Open live ↗

What it does: staff apply for leave, a boss approves it, and days beyond the yearly quota are automatically cut from that month's salary.

Staff applies➜ HOD / HR / Boss decides➜ Approved / Rejected➜ Over-quota days dock payslip
Log in as teacher@sainik01.edu · Demo@Teacher1 → Leaves → apply (Casual / Sick / Earned / Duty / Unpaid).
Log in as hr@sainik01.edu · Demo@Hr1 (or hod) → Approve or Reject — rejection needs a reason.
Log in as principal@sainik01.edu · Demo@Principal1 → Staff → “My payslips” shows the effect on pay.
Rule: nobody approves their own leave — try hod@… on his own application and watch it refuse. Quotas: Casual 12 · Sick 8 · Earned 15 · Duty 10 · Unpaid = every day cuts salary.
✅ Complete & live: verified — 3 unpaid days docked ₹3,000 from a ₹30,000 salary.
6

🧒 Student Leave — a child stays homeparent asks → staff decides → attendance pre-filled

Open live ↗

What it does: the parent asks for leave for their child; once approved, the attendance sheet pre-fills the child as “Leave” so no teacher marks them absent by mistake.

Parent requests➜ Warden / Teacher / HOD decides➜ Attendance & hostel roll-call pre-filled ✨
Log in as parent@sainik01.edu · Demo@Parent1 → Portal → Leaves → request for the child.
Log in as warden@sainik01.edu · Demo@Warden1 (or teacher/hod) → Approve or Reject — parent gets a message either way.
Log in as teacher@sainik01.edu · Demo@Teacher1 → Attendance → the child already shows “Leave”.
Rule: only the person who filed the request can cancel it — and only while it's still Pending.
✅ Complete & live: portal request, overlap check, auto-fill into attendance & roll-call.
7

📇 Exams & Report Card — marks in, result outthe publish gate · plus online CBT tests

Open live ↗

What it does: the school announces exams, teachers enter marks, grades and ranks are computed — and only when a boss PUBLISHES can the family see the card.

HOD: exam + bands➜ Teacher marks (Provisional)➜ HOD/Boss PUBLISHES➜ Family portal sees it 🎉
Log in as hod@sainik01.edu · Demo@Hod1 → Exams → create the exam + grade bands.
Log in as teacher@sainik01.edu · Demo@Teacher1 → enter marks (card says “Provisional” — family sees nothing yet).
Back to hod@… (or principal) → Publish the report cards.
Log in as parent@sainik01.edu · Demo@Parent1 → Portal → Results → the card appears.
Bonus: log in as student@sainik01.edu · Demo@Student1 → Tests → attempt the online CBT (server timer, MCQs self-check, teacher grades essays).
Rule: Publish is the gate — before it no parent or student can see any mark. Half-finished results can never leak.
✅ Complete & live: grades, ranks, PDF cards, publish-freeze, CBT with grading queue.
8

💰 Payroll — salary month closegenerate → finalize → paid → staff downloads own slip

Open live ↗ (Payroll tab)

What it does: every month HR/accounts create everyone's payslip (tax, EPF, leave deductions already computed), approve the batch, mark it paid — then each staff member sees only their own slip.

HR generates➜ Draft➜ Finalize = Generated➜ Mark Paid➜ Staff PDF download
Log in as hr@sainik01.edu · Demo@Hr1 (or accounts) → Staff → Payroll → Generate → Finalize → Mark Paid.
Log in as teacher@sainik01.edu · Demo@Teacher1 → Staff → “My payslips” → download the PDF. He sees ONLY his own.
Rule: salary is invisible in the staff directory, and a slip can't be marked Paid before Finalize — no shortcuts.
✅ Complete & live: tax slabs, EPF, professional tax, leave-docking, payslip PDFs.
9

🧭 Timetable & the “teacher is sick” chainauto-generated grid · auto-substitutes

Open live ↗

What it does: builds the whole school's weekly timetable automatically with zero clashes — and when a teacher is absent, instantly finds a substitute for every free period.

HOD generates➜ Teacher marked Absent➜ AUTO substitutes➜ Substitute emailed + class notice
Log in as hod@sainik01.edu · Demo@Hod1 (or principal) → Timetable → Generate → the full grid appears, no double-bookings.
Same login → mark a teacher Absent for today → covers appear for all their periods.
Log in as the substitute (e.g. teacher@sainik01.edu · Demo@Teacher1) → “My Day” shows the extra class.
Rule: the system checks the substitute's own classes, approved leave and exam duty before assigning — never double-booked. Warden & Security can't see this page at all.
✅ Complete & live: constraint solver, bulk substitution, master/today PDFs, exam duty.
10

🛡️ Discipline — the secret safety filesanyone can report · only 3 logins can read

Open live ↗

What it does: any staff member can report a child-safety or behaviour concern; it becomes a confidential case only three people in the school can open — and every view is logged.

Any staff reports➜ Open➜ Case team: Review → Close➜ High/Critical = auto-alert to principals
Log in as teacher@sainik01.edu · Demo@Teacher1 → Discipline → report an incident. He can later see only his own report.
Log in as discipline@sainik01.edu · Demo@Discipline1 → open the real case file → review → close.
Log in as principal@sainik01.edu · Demo@Principal1 → re-open a closed case (reason required) or delete.
🧪 Proof test: log in as schooladmin@sainik01.edu · Demo@Admin1 — otherwise all-powerful — and the case files are NOT there.
Rule: only super_admin, principal and the safeguarding lead read these files. Confidential notes never enter any parent message; every view is written to the audit log.
✅ Complete & live: cases, escalation, row-level confidentiality, full audit trail.

The fine print, made simple

The 4 rules that explain the whole system

🚪

Right person, right door

Screens and buttons appear only for roles that need them — and the server checks again on every action, so nothing can be faked.

📝

Every NO leaves a note

Approvals and rejections store who did it, when, and why. The audit log can replay any file's whole life.

🫧

Families live in a bubble

A parent sees only their children; a student only themselves. One school can never see another school's data.

📲

The system tells the family

Absence, gate pass, fee receipt, admission step, leave result — a message reaches the parent automatically at every turn.
