Security & Compliance

Government-grade security.
Non-negotiable.

🔑

JWT Role-Based Access Control

Every API endpoint requires a signed JWT token. Super Admin, Branch Admin, Principal, Warden, and Teacher roles are strictly enforced — nobody can access data outside their role.

HS256 JWT + alg enforcement
🛡️

SQL Injection Prevention

100% of database queries use D1's parameterized prepared statements. No string concatenation. No raw SQL with user input — ever.

.prepare().bind() throughout
🪣

Campus-Wise Data Isolation

Every table row carries a branch_id. Document storage is segmented into separate R2 buckets per campus. A Lucknow school admin cannot see Pune's data.

Row-level branch_id scoping
🔒

Webhook Security (Biometric)

The CAMS biometric webhook requires a pre-shared API key in the HTTP header. Anonymous requests are rejected immediately with a 401.

x-api-key header enforcement
